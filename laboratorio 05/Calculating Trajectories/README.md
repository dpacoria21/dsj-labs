# Calculating Trajectories — Laboratorio 05

Proyecto Unity **6000.3.15f1** para el apartado V.4 de la guía, basado en el paquete oficial **S0311Resources** de [Unity Learn](https://learn.unity.com/tutorial/calculating-trajectories).

- Escena principal: `Assets/Tanks.unity`.
- Abrir con Unity Hub y pulsar Play.
- Objetivo: tanque rojo; WASD/flechas para moverlo.
- L alterna arco alto/bajo. R reinicia.
- El tanque verde calcula, apunta y dispara automáticamente usando Rigidbody **3D**.
- Build local: `Builds/Windows/Calculating Trajectories.exe`.
- [Desarrollo, autoría, adaptaciones y verificación](../docs/TUTORIAL.md).
- Fuente oficial sin modificar: `SourcePackages/S0311Resources.zip`.

Se conserva la estructura Assets/Packages/ProjectSettings del laboratorio 02. Library y Builds son archivos locales generados y están excluidos por el `.gitignore` del repositorio.
