# Coloca aquí tus imágenes

| Nombre exacto | Uso | Tamaño de dibujo |
| --- | --- | --- |
| background.jpg | Fondo | 800 × 600 px |
| ufo.png | Icono de la ventana | 32 × 32 px |
| player.png | Nave del jugador | 64 × 64 px |
| enemy.png | Enemigos | 64 × 64 px |
| bullet.png | Disparo | 32 × 32 px |

Conserva estos nombres y extensiones. Los archivos se ajustan automáticamente al tamaño de dibujo; se recomienda PNG transparente para las naves y el disparo. Puedes colocarlos con el juego cerrado y volver a ejecutar `main.py`, sin cambiar código.

Mientras falte alguna imagen, se dibuja una figura provisional para ese recurso. No se han incluido ni descargado imágenes.
