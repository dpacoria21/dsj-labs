# Actividades - Waypoints

Abre esta carpeta como proyecto con **Unity 6000.3.15f1**.

Escena: `Assets/Scenes/01_Actividades_TankRacing.unity`.

Pulsa **Play** para ver los cuatro tanques recorrer las nueve palmeras. Selecciona un tanque en el panel o en el Inspector para experimentar con `speed`, `rotSpeed` y `accuracy`. **C** cambia la cámara, **R** reinicia y **Espacio** pausa.

El ejecutable `Builds/Lab06.exe` se generó localmente y no se incluye en GitHub. Para crearlo, compila para Windows desde **File > Build Profiles**; también puedes probar la escena directamente con **Play**.

La escena original del material se conserva en `Assets/TankRacing.unity`. La escena terminada está en `Assets/Scenes`.

Consulta `../README.md` para la correspondencia con las 15 actividades, controles y fuentes. `Verificacion/resultado.txt` registra las 15 comprobaciones completadas sin errores.
